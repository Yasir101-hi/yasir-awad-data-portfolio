# Yasir Awad — Data Analyst & Business Intelligence Portfolio

Professional portfolio showcasing data analytics and business intelligence projects built with Power BI, SQL, Python, and Excel.

## Featured projects

- **Retail Business Intelligence Dashboard** — Sales, customer, product, and branch performance analysis in Power BI.
- **University Database Analysis** — Student performance, course capacity, and teaching-quality analysis using SQL, Python, and Power BI.
- **Oil Well #807 Production Analysis** — Production decline, pressure, and water-cut analysis using Python.
- **Global Data Science Survey Analysis** — Analysis of 106,301 survey responses covering demographics, roles, and geographic participation.

## Technology

- React 18 and TypeScript
- Vite
- CSS
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
